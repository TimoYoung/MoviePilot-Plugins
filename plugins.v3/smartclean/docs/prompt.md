# 智能清理媒体库

## 媒体库配置

媒体库信息要依赖真实的媒体库（如jellyfin），而非moviepilot维护的媒体转移记录。要考虑到有些媒体不是通过moviepilot入库的。清理对象仅限于媒体库类型为电影/电视剧的

## 筛选逻辑

- 白名单：名单上的媒体不删除。支持用户从媒体库点选加入白名单，支持按豆瓣id导入白名单
- 豆瓣看过：关联主用户的豆瓣id。插件要可以设置豆瓣用户，删除星级阈值，删除时间阈值。根据用户的看过时间和打分，可以根据打分过滤比如“豆瓣标记看过超过七天且不高于4星的”
  - 关联媒体项和豆瓣词条的逻辑可以参考 /Users/timoyoung/PyProjects/douban250 项目的相关实现
- 按照媒体的添加用户和添加时间筛选，比如“a用户订阅的媒体入库超过了30天” 逻辑参考 /Users/timoyoung/PyProjects/MoviePilot/MoviePilot-Plugins/plugins.v3/autoclean

- 其他筛选逻辑你可以给出更多补充建议
- 不同筛选维度之间可以按与/或的逻辑组织

## 清理逻辑

- 支持定时执行和立即执行
- 清理方式支持选择源文件/媒体库文件/所有文件。
  - 由于清单上的媒体有可能是moviepilot管理入库的，有可能不是，要考虑具体实施策略
- 支持确认后执行/测试执行（dry run）。支持设置一个延迟删除的天数。满足筛选逻辑的媒体会进入一个冻结的待删除清单，从任务执行开始算，超过延迟删除的时间后无需确认自动删除

- 确认执行的确认操作前/测试执行会展示待删除清单。要展示删除原因（命中的筛选规则）。可以在此页面对媒体项手动删除或添加白名单
- 维护删除媒体的历史记录，支持一键清空

## 其他

- 尽量复用moviepilot的底层设施，实在必要再自己新建和维护（如媒体和豆瓣词条的信息）
- 尽量支持moviepilot v3插件的最新特性和能力。
- 交互要友好，直观，符合直觉，所有配置都尽量允许用户点选而非输入。
